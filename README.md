# unix-cli-emulator

Вариант 5

Эмулятор unix-оболочки на Python: своя виртуальная файловая система (VFS) и интерактивный CLI.
Работает в терминале, не трогает реальную FS хоста.

## Запуск

Подготовка окружения (один раз):

```bash
./setup.sh
```

Запуск эмулятора:

```bash
./run.sh
```

или вручную:

```bash
cd src && python3 main.py
```

Промпт выглядит так: `root@Emulator:~$`

---

## Общее описание

Проект состоит из трёх модулей в `src/`:

| Файл | Назначение |
|------|------------|
| `main.py` | Точка входа |
| `CLI.py` | Разбор команд и цикл оболочки |
| `VFS.py` | Виртуальная ФС (имя хоста, текущий каталог) |

Скрипты в корне:

| Скрипт | Назначение |
|--------|------------|
| `setup.sh` | Создаёт `.venv`, если его ещё нет |
| `run.sh` | Активирует venv (если есть) и запускает `main.py` |

---

## Команды оболочки

Ввод: `команда [аргументы...]`. Пустые аргументы отбрасываются.

| Команда | Описание |
|---------|----------|
| `ls [args...]` | Пока заглушка: печатает имя команды и каждый аргумент |
| `cd [args...]` | Пока заглушка: печатает имя команды и каждый аргумент |
| `exit` | Выход из цикла оболочки |
| любое другое | `command not found: <имя>` |

## Модули и функции

### `main.py`

**`run()`**  
Создаёт экземпляр `CLI` и вызывает `CLI.run()`.

При запуске файла напрямую (`python3 main.py`) вызывается `run()`.

---

### `CLI` (`CLI.py`)

Интерактивная оболочка.

#### Поля / настройки

| Поле | По умолчанию | Описание |
|------|--------------|----------|
| `vfs` | экземпляр `VFS` | Связанная виртуальная ФС |
| `user` | `"root"` | Имя пользователя в промпте |

В `__init__` также выставляется `vfs.activate_directory = "~"` (стартовый каталог для оболочки).

#### Методы

**`__init__()`**  
Создаёт `VFS`, задаёт стартовый каталог и пользователя `root`.

**`run()`**  
Бесконечный цикл:

1. Строит промпт: `{user}@{vfs.name}:{vfs.active_directory}$ `
2. Читает строку, сплитит по пробелам
3. Первое слово — команда, остальное — аргументы
4. Обрабатывает `exit` / `ls` / `cd` или печатает ошибку

---

### `VFS` (`VFS.py`)

Виртуальная файловая система (пока минимальная модель состояния).

#### Поля / настройки

| Поле | По умолчанию | Описание |
|------|--------------|----------|
| `name` | `"Emulator"` | Имя «хоста» в промпте (`user@name:...`) |
| `active_directory` | `"~"` | Текущий каталог в промпте |

#### Методы

**`__init__()`**  
Инициализирует `name` и `active_directory`.
